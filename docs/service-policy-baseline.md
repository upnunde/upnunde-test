# 서비스 정책 기준서

이 문서는 Re:Novel 서비스 전반에서 반복적으로 참조하는 핵심 정책을 모아 둔 기준 문서입니다.  
기능 구현, 화면 카피, 운영 정책 반영 시 본 문서를 우선 기준으로 삼습니다.

---

## 1) 핵심 컨셉 한눈에

### Ink — 인터랙티브 대본 언어
- Ink는 영국 inkle studios가 만든 내러티브 스크립팅 언어입니다.
- 대화, 분기, 변수, 태그를 자연스럽게 표현할 수 있어 비주얼 노벨/인터랙티브 픽션에 널리 쓰입니다.
- Re:Novel은 Ink를 기반으로 모든 결정적(deterministic) 스토리 흐름을 표현합니다.

### 핸드오프(Handoff) — 스토리에서 AI로 넘어가는 순간
- 정해진 대본만으로 표현하기 어려운 대화 구간에서 Ink 태그(예: `#enter_ai_chat`) 또는 스토리 끝 도달 시 AI 챗 모드로 전환합니다.
- 이 전환 시점을 핸드오프라고 정의합니다.

### 시리즈 / 에피소드 / 캐릭터
| 개념 | 의미 | 특징 |
|---|---|---|
| 시리즈 | 하나의 작품(연재물) | 대표 이미지, 캐릭터 목록, 에피소드 묶음, 큐레이션 노출 단위 |
| 에피소드 | 시리즈 안의 한 화 | Ink 스크립트 기반, 자동 저장, 유료/무료 분기 가능 |
| 캐릭터 | 작품 속 인물 | 일러스트, Spine 애니메이션, 자체 Ink 도입부(`ink_url`), 캐릭터 챗 진입 포인트 |

### 두 가지 챗 모드
| 구분 | 시리즈 챗 | 캐릭터 챗 |
|---|---|---|
| 진입 | 에피소드 중 핸드오프 | 캐릭터 상세 → 새 AI 채팅 |
| Ink 역할 | 본편 스토리 | AI 챗 도입부(뷰어) |
| 유료 선택지 | 있음 | 없음(있어도 무료) |
| 진행도 저장 | 저장 | 매번 처음부터 |
| 호감도 | 반영 | 해당 없음 |
| 스킵 | 가능 | 비활성(의도적) |

### 페르소나 — 작품 속 “나는 누구인가”
- 유저는 작품에서 사용할 자신의 캐릭터를 페르소나로 생성합니다.
- 구성: 이름 + 설명(최대 1000자)
- 여러 개 생성 가능하며, 시리즈마다 다른 페르소나를 지정할 수 있습니다.

### 유저노트 — “이 대화에서 기억할 것”
- 페르소나가 정체성이라면, 유저노트는 해당 세션에서 AI가 기억해야 할 메모입니다.
- 세션 단위, 최대 1000자입니다.

### World State — 화면 일관성 시스템
- Ink 태그(예: `# bg: ...`, `# spine: ...`)를 받아 배경/캐릭터/BGM 등의 화면 상태를 자동 정리합니다.
- 스토리 진행 중 시각/연출 일관성을 보장하는 장치입니다.

## 2) 주요 기능 — 시리즈 플레이

“에피소드 한 화를 처음부터 끝까지 플레이”하는 기본 사용자 흐름입니다.

### 플레이 진입 단계
1. 시리즈 선택 → 시리즈 상세에서 에피소드 선택
2. 리소스 프리로드 — 배경, 캐릭터 이미지, BGM 등을 미리 다운로드 (`SeriesLayoutData.resources`)
3. 대화 테마 초기화 — 시리즈가 지정한 `chat_theme_key` 로드 (미지정 시 `toon002`)
4. 스토리 로드 — 해당 에피소드 Ink 스크립트 로딩
5. 플레이 시작 — 첫 진입은 `NewStart_Story`, 이어보기는 `Continue_Story`

### 플레이 중 화면 요소
- 대화창: 현재 라인 텍스트와 화자 이름. 터치로 다음 라인 진행
- 상단 표시: `top_desc`(장소/시간), 턴(`turn/total_turn`) 등 메타 정보
- 스킵 버튼: 다음 선택지까지 빠르게 진행 (선택지 노출 중 숨김)
- 설정: 대화 페르소나, 유저노트, 로그, 사운드

### 선택지(Choice)
- Ink의 `choice` 도달 시 선택지 UI를 표시합니다.
- 일부 선택지는 유료(10코인)이며, 선택 시 코인 차감 확인 팝업을 노출합니다.
- 무료 선택지는 0코인입니다.
- 선택 결과는 `progress_data`에 기록되며, 재진입 시 동일 분기로 이어집니다.

### 자동 저장과 이어하기
- 선택지 통과, 태그 적용, World State 반영 등은 주기적으로 저장됩니다.
- 이어하기는 `RestoreStory` / `RestoreCompletedStory` 흐름으로 마지막 지점에서 시작합니다.
- 완료 에피소드는 리플레이 모드(`Replay_Story`)로 재생 가능하며, 이때 스킵/일부 기능이 제한됩니다.

### 핸드오프(AI 챗 전환) 시점
- Ink가 `#enter_ai_chat` 태그를 만났을 때
- 또는 Ink가 더 진행할 수 없는 끝점(`!canContinue`)에 도달했을 때  
  - 일부 모드에서는 이 시점에도 AI 챗으로 전환됩니다.

### 라이크빌리티(호감도)
- 시리즈 플레이는 캐릭터 호감도에 영향을 줄 수 있습니다.
- 변동은 Ink 변수로 감지되며, 엔딩 분기 결정에만 사용됩니다.
- 갤러리 해금에는 사용되지 않습니다.

## 3) 주요 기능 — 캐릭터 챗

캐릭터 상세 페이지에서 즉시 캐릭터와 AI 대화를 시작하는 모드입니다.  
핵심 목적은 이야기 진행이 아니라 “대화 경험”입니다.

### 한 줄 정리
- 시리즈를 끝까지 보지 않아도, 좋아하는 캐릭터와 바로 대화할 수 있습니다.

### 진입 방법
1. 메인 캐릭터 탭 또는 시리즈 상세에서 캐릭터 카드 선택
2. 캐릭터 상세에서 “새 AI 채팅” 버튼 탭
3. 해당 캐릭터의 짧은 Ink 도입부 재생(뷰어 역할)
4. AI 챗 모드로 전환

### 시리즈 챗과의 주요 차이
- Ink는 뷰어 역할만 수행하며, 코인 차감/진행도 저장이 없습니다.
- 호감도 변동이 발생하지 않습니다(엔딩 분기 영향 없음).
- 스킵 버튼은 비활성입니다(짧은 도입부 전제).
- 채팅 세션 생성 API가 분리됩니다 (`/chat/character/start`).

### 이어하기
- 시작한 캐릭터 챗은 채팅 세션으로 보관됩니다.
- 캐릭터 상세의 “이어하기”로 최근 채팅을 계속 진행할 수 있습니다.
- 현재 정렬 기준은 `updated_at` 최신순입니다.

### 주의사항
- 캐릭터 챗의 페르소나/대화 테마/일부 UI 분기는 일부 구간에서 임시 폴백으로 동작할 수 있습니다.
- 상세 상태는 로드맵의 미해결 항목을 함께 참고합니다.

## 4) 주요 기능 — AI 챗(핸드오프)

스토리 화면에서 AI 챗으로 전환되고, 필요 시 다시 스토리로 복귀하는 핵심 흐름입니다.

### 흐름 요약
```text
[Ink 스토리]
   │   #enter_ai_chat 태그 또는 ink end
   ▼
[AI Chat UI 전환]
   │   첫 메시지 전송
   ▼
[POST /chat/handoff 또는 /chat/character/start]
   │   chat_session_seq 발급
   ▼
[메시지 송수신 — 스트리밍]
   │
   └─ 캐릭터/시리즈 정의에 따라 종료 후 다시 Ink로 복귀
```

### 핵심 데이터
- `chat_session_seq`: 한 번의 챗 세션 고유 ID (이어하기 키)
- `user_persona_seq`: 해당 세션에서 사용할 페르소나 식별자
- `persona_name`: Ink/AI 응답의 `{Name}` 치환 이름
- `user_note`: 대화 중 기억 메모(최대 1000자)
- `world_state`: 핸드오프 시점의 화면/씬 스냅샷

### 스트리밍 응답
- AI 응답은 스트리밍으로 점진 표시됩니다.
- 중간 취소/재전송이 가능하며, 종료 시 최종 텍스트로 확정됩니다.

### 유저노트 정책
- 유저노트는 “이 대화에서 잊지 말아야 할 것”을 적는 세션 메모입니다.
- 입력 위치: 플레이 중 설정 화면
- 최대 길이: 1000자, 저장 버튼으로 반영
- 세션 프롬프트에 함께 전달되어 응답 톤/기억을 보정합니다.
- 캐릭터 챗 첫 진입(세션 생성 전)에서는 비활성입니다.

### 유저노트 작성 예시
- “나는 커피를 안 마신다. 음료를 권하면 차로 바꿔 줘.”
- “여동생 이름은 ‘하린’. 이전 대화에서 시험 본다고 했음.”
- “반말로 말해 줘. 이모지는 쓰지 마.”

### 작성 가이드
- “나는 23살 디자이너야”처럼 정체성 정보는 유저노트보다 페르소나 설명에 작성하는 것을 권장합니다.

### 이상 처리
- 핸드오프 API 실패: 토스트 안내 + 입력창 복원
- 네트워크 끊김: 마지막 시도 메시지 보존
- 세션 만료/유효성 오류: 이어하기 목록에서 재진입 유도

## 5) 주요 기능 — 페르소나 시스템

페르소나는 “나는 누구인가”를 AI에 전달하는 유저 정체성 카드입니다.  
이름과 설명으로 구성되며, 유저는 여러 페르소나를 만들어 작품/세션별로 다르게 사용할 수 있습니다.

### 페르소나 vs 유저노트
- 페르소나: 정체성/배경/성격 등 “나는 누구인가”를 정의
- 유저노트: 대화 중 기억해야 할 메모를 정의
- 두 항목 모두 최대 1000자까지 작성 가능

### 왜 필요한가
- 동일 작품이라도 페르소나 설정에 따라 AI 응답이 달라집니다.
- 유저는 작품별로 다른 분신(페르소나)을 적용할 수 있습니다.

### 데이터 구조
| 필드 | 설명 | 한도 |
|---|---|---|
| `name` | 표시 이름 (`{Name}` 치환값) | 짧은 이름 |
| `description` | 정체성/배경/성격 설명 (프롬프트 반영) | 최대 1000자 |
| `created_at`, `updated_at` | 생성·수정 시각 | - |

### CRUD 정책
- 생성: 메인 → 내 페르소나 → 추가
  - 이름/설명 입력
  - 설명은 최대 1000자
  - 한국어/영어/숫자/공백 허용
- 조회: 리스트는 생성순(과거 → 최신)
- 수정: 항목 메뉴의 수정 기능 사용, 실시간 글자수 카운터 표시
- 삭제: 항목 메뉴의 삭제 기능 사용
  - 페르소나가 1개뿐이면 삭제 불가

### 적용 단위
| 구분 | 시리즈 챗 | 캐릭터 챗 |
|---|---|---|
| 적용 범위 | 해당 시리즈의 향후 채팅 전체 | 해당 채팅 세션 1개 |
| 기본값 | 시리즈 기본(서버 제공) 또는 직전 선택 | 페르소나 리스트 첫 번째 항목 |
| 저장 API | `PUT /user/persona/series/{seriesSeq}` | `PUT /chat/{chatSessionSeq}/persona` |

### 이름 결정 우선순위
1. 현재 시리즈의 `user_persona_data.name`
2. 현재 챗 세션의 `user_persona_seq`로 매칭한 페르소나
3. 페르소나 리스트의 첫 번째(`[0]`)
4. 시리즈 기본 이름(`default_persona_name`)

### 회원가입 기본 페르소나
- 회원가입 시 닉네임 기반 기본 페르소나 1개를 생성합니다.
- 닉네임 변경 시 페르소나 이름은 자동 변경되지 않습니다(직접 수정 필요).

### 작성 가이드 (작가용)
- Ink에서 유저 지칭 시 `{Name}`을 사용합니다.
- 플레이 시 `{Name}`은 현재 페르소나 이름으로 자동 치환됩니다.

## 6) 주요 기능 — 코인 · 결제

Re:Novel 내 콘텐츠 이용을 위한 인앱 재화(코인) 정책입니다.

### 가격표 (요약)
| 항목 | 코인 | 설명 |
|---|---|---|
| 회원가입 보너스 | +130 | 가입 시 1회 자동 지급 |
| 에피소드 1, 2화 | 무료 | 모든 시리즈 공통 |
| 에피소드 3화부터 | -30 | 회차당 차감, 해금 후 재방문 추가 차감 없음 |
| AI 채팅 | -8 / 건 | 유저 메시지 1건당 차감(스트리밍 응답 1회 기준) |
| 유료 선택지 | -10 | 코인 아이콘 선택지에만 차감, 무료 선택지는 0코인 |

### 코인 획득 방법
- 가입 보너스: 최초 가입 시 130코인 자동 지급
- 결제(충전): 인앱 결제(RevenueCat 기반)
- 쿠폰: 운영 발급 쿠폰을 마이페이지에서 등록

### 코인 사용처
- 에피소드 해금: 3화부터 진입 시 30코인 차감 (1, 2화 무료)
- AI 채팅: 메시지 1건당 8코인 차감 (시리즈/캐릭터 챗 동일 단가)
- 유료 선택지: 코인 아이콘 선택지 10코인 차감

### 이용 예시 (가입 직후)
- 예시 1: 3화 해금(30) + AI 채팅 12건(96) = 약 126코인
- 예시 2: 1,2화 무료 + 3화 해금(30) + 유료 선택지 10회(100) = 130코인

### 충전/잔액
- 충전은 인앱 결제(RevenueCat 기반)로 수행
- 잔액은 메인/플레이 상단 또는 마이페이지에서 확인
- 지역별 화폐·과세 표시는 운영 정책에 따라 어드민에서 관리

### 차감 흐름
- 에피소드 진입(3화 이상): “30코인 사용” 확인 팝업 → 확인 시 차감 → 진입
  - 잔액 부족 시 충전 화면 이동
- 유료 선택지: “10코인 사용” 확인 팝업 → 확인 시 차감
- AI 채팅: 메시지 전송 직후 8코인 차감
  - 응답 실패 환원 정책은 운영 측 별도 안내
- 재방문: 이미 해금한 에피소드/통과한 유료 선택지는 재차감 없음

### 환급 정책
- 환급은 스토어/지역 약관을 따릅니다.
- 운영은 어드민 쿠폰/보상 지급으로 별도 보상 정책을 운영할 수 있습니다.

## 7) 주요 기능 — 호감도 · 갤러리

호감도와 갤러리는 함께 언급되지만, 정책적으로는 별개 시스템입니다.

### 핵심 구분
- 호감도는 엔딩 분기 결정용입니다.
- 갤러리 해금은 별도 해금 조건으로 동작합니다.
- 호감도는 갤러리 해금에 영향을 주지 않습니다.

### 호감도(Likability)
- 캐릭터별 누적 관계 점수입니다.
- Ink 스토리 변수로 증감되며, 시리즈 챗에서만 반영됩니다(캐릭터 챗 미반영).
- 증감 시점에 화면에 짧은 표시(아이콘/수치)가 노출될 수 있습니다.
- 용도는 엔딩 분기 판단이며, 임계값/조건 조합으로 엔딩이 달라집니다.

### 갤러리(이미지 해금)
- 갤러리 해금은 호감도와 무관합니다.
- 해금은 이벤트/분기 통과, 특정 에피소드 완료 등 별도 조건으로 수행됩니다.
- 갤러리는 캐릭터 상세 또는 시리즈 메뉴에서 확인합니다.
- 해금 이미지는 풀스크린 뷰어로 감상할 수 있습니다.

### 엔딩과의 연결
- 호감도 임계값과 분기 선택 조합으로 도달 엔딩이 결정됩니다.
- 엔딩 도달 후 리플레이 모드로 다시 감상할 수 있습니다.

## 8) 주요 기능 — 스킵 · 리플레이

### 스킵(Skip)
에피소드를 빠르게 “다음 선택지 직전”까지 진행시키는 기능입니다.

- 노출 조건: 첫 플레이(`NewStart_Story`) / 이어하기(`Continue_Story`)에서만 노출
- 숨김 조건: 리플레이, AI 챗, 캐릭터 챗, 선택지 표시 중
- 동작 방식:
  - 다음 선택지까지 무음 진행
  - 씬 전환 태그는 최종 상태만 반영
  - SFX/TTS/파티클은 스킵
- 확인 팝업:
  - “다시 보지 않기”를 체크하기 전까지 매번 노출
- 완료 후:
  - 자동 저장 수행
  - 스토리 끝 도달 시 정상 종료 흐름 진입

### 리플레이(Replay)
완료된 에피소드를 다시 감상하는 모드입니다 (`Replay_Story`).

- 코인 차감 없음
- 호감도 증감 없음
- 진행 저장 없음
- 선택지 기본 선택은 직전 통과 선택으로 자동 표시
- 리플레이 모드에서는 스킵 버튼 미노출

### 캐릭터 챗의 스킵 정책
- 캐릭터 챗에서는 의도적으로 스킵을 비활성화합니다.
- 이유: 도입부가 짧아 스킵 실익이 낮고, AI 챗으로 자연스럽게 연결되도록 하기 위함입니다.

## 9) 세계관 · 연출 — 월드 스테이트(World State)

월드 스테이트는 배경/캐릭터/BGM/UI 상태를 자동 정리해 화면 일관성을 유지하는 시스템입니다.

### 왜 필요한가
- 작가가 Ink 태그로 화면 상태를 지시할 때, 동시 입력/저장·복원/AI 핸드오프 과정에서 상태 충돌이 발생할 수 있습니다.
- 월드 스테이트는 충돌을 정규화해 깨짐 없는 연출을 유지합니다.

### 관리 필드
| 카테고리 | 필드 | 의미 |
|---|---|---|
| 배경 | `bg` | 정적 배경 이미지 |
| 배경 | `bgmov`, `bgmov_loop` | 배경 영상 + 반복 여부 |
| 배경 | `event_bgmov` | 이벤트 전용 풀스크린 영상 |
| 배경 | `bgm` | 배경 음악 |
| 캐릭터 | `spine`, `pose` | Spine 애니메이션 + 포즈 |
| 캐릭터 | `char_img` | 정적 캐릭터/소품 이미지 |
| UI | `top_desc` | 상단 좌측 설명(예: `{Name}`의 방 / 아침) |
| UI | `turn`, `total_turn` | 현재/총 턴 표시 |
| UI | `is_event_ui` | 이벤트 UI 표시 여부 |

### 핵심 규칙: 배타 그룹
- 배경 3-way 배타: `bg` ↔ `bgmov` ↔ `event_bgmov`
  - 새 배경 태그 입력 시 나머지 배경 계열은 자동 초기화
- 이벤트 영상 우선: `event_bgmov` 입력 시 캐릭터(`spine/pose/char_img`)까지 자동 초기화
- 캐릭터 2-way 배타: `spine+pose` ↔ `char_img`
  - `spine` 없이 `pose`만 입력되면 무시
  - `char_img` 활성 상태에서 `pose` 입력 시 적용되지 않음

### 정규화(Normalize) 규칙
저장 후 복원 시점에 아래 우선순위로 재정렬합니다.

- 배경 우선순위: `event_bgmov > bgmov > bg`
- 캐릭터 우선순위: `spine > char_img`
  - `spine`이 없으면 `pose`도 제거
- 영상 배경 상태에서는 캐릭터를 강제 클리어

### 자주 발생하는 함정
- `pose` 미적용: `char_img`가 활성인지 확인 후, `spine`을 먼저 세팅
- 이벤트 영상 후 캐릭터 소실: 의도된 동작이며, 캐릭터를 다시 보이려면 `spine` 또는 `char_img` 재지정 필요
- 캐릭터 숨기기: 값 없는 `# char_img:` 한 줄로 처리
- 영상에서 정적 배경 복귀: `# bg: ...` 지정 시 영상 필드는 자동 정리

## 10) 세계관 · 연출 — 대화 테마

대화 테마는 플레이 화면의 대화창/로그/UI 톤을 작품 분위기에 맞게 교체하는 시스템입니다.

### 구조
- 각 테마는 에셋 번들 단위로 관리합니다.
- 식별 키는 `chat_theme_key` (예: `toon002`)를 사용합니다.
- 시리즈별로 개별 테마를 지정할 수 있습니다.
- 시리즈에 테마가 없으면 기본 테마 `toon002`를 적용합니다.

### 적용 시점/순서
플레이 모드 진입 직전에 아래 순서로 적용합니다.
1. 번들 다운로드
2. 프리팹 교체
3. UI 인스턴스 재구성

### 별도 테마 운영 이유
- 작품별 톤 차이를 UI에 반영하기 위함입니다.
- 번들 분리 방식으로 앱 재배포 없이 운영에서 신규 테마를 추가할 수 있습니다.

### 캐릭터 챗 테마 정책
- 현재 캐릭터 챗은 시리즈 컨텍스트 없이 진입하므로 기본 `toon002`를 일괄 적용합니다.
- 추후 캐릭터 단위 테마 지정 확장을 예정합니다.

## 11) 사용자 여정 — 신규 유저 여정(Day 0)

가입부터 첫 AI 챗, 재진입까지의 기본 사용자 흐름입니다.

### 1) 가입 직후
- 닉네임 입력 후, 닉네임 기반 기본 페르소나 1개 자동 생성
- 약관/푸시 알림 동의
- 가입 보너스 130코인 자동 지급
- 온보딩(없거나 짧은 단계) 후 메인 도착

### 2) 작품 탐색
- 큐레이션 배너/베스트/신작에서 시리즈 선택
- 시리즈 상세에서 캐릭터/줄거리 사전 확인
- 1화 무료로 시작(1, 2화는 공통 무료)
- 3화부터 진입 시 30코인 차감

### 3) 첫 플레이
- 로딩 후 대화창에서 터치로 라인 진행
- 선택지 도달 시 분기 선택(유료 선택지는 코인 아이콘 노출)
- 중간/끝 시점에서 AI 챗 핸드오프 진입 가능

### 4) 첫 AI 챗
- 유저 첫 메시지 전송으로 챗 세션 생성
- 채팅 UI 전환, 페르소나 이름 자동 적용
- 설정에서 유저노트 입력 시 응답 정합도 향상

### 5) 첫 종료 & 재진입
- 앱 재실행 시 메인에 “이어보기” 카드 노출
- 이어보기 진입 시 마지막 플레이 지점/세션 자동 복원

## 12) 사용자 여정 — 기존 유저 여정

이미 여러 작품을 경험한 유저의 반복 행동 패턴입니다.

### 1) 좋아하는 캐릭터와 짧은 대화
- 메인/시리즈 상세에서 캐릭터 카드 진입
- 캐릭터 상세에서 이어하기(최근 세션) 또는 새 AI 채팅 선택
- 5~10분 캐릭터 챗 이용 후 종료

### 2) 다음 화 소비
- 메인의 이어보기 카드에서 시리즈 상세 진입
- 다음 에피소드 진입 후 자동 저장 지점부터 시작
- 유료 선택지에서 코인 사용 여부 결정
- 엔딩/이벤트 분기 후 갤러리 해금 여부 확인

### 3) 페르소나 재설정
- 설정/메인에서 내 페르소나 진입
- 신규 페르소나 생성(다른 톤/설정) 또는 기존 수정
- 현재 시리즈 적용 페르소나 변경
- 이후 챗에서 응답 톤 변화 확인

### 4) 결제·환급 문의 흐름
- 마이페이지에서 결제 내역/잔액 확인
- 코인 부족 시 충전 또는 쿠폰 적용
- 운영 지급/쿠폰은 어드민 발급 후 유저 계정에 반영
